# Состояние проекта Norravia

## Название и назначение

Norravia — сайт-визитка новой норвежской авиакомпании с главным хабом в Осло.

## Что должна делать программа

Сайт должен знакомить посетителя с компанией, показывать интерактивную карту будущих маршрутов, рассказывать о сервисе и отображать дату запуска 17 декабря 2026 года. Сайт не собирает данные посетителей.

## Основные файлы и папки

- `index.html` — готовая одностраничная страница, её стили, SVG-карта и JavaScript.
- `assets/images/` — пять сгенерированных изображений в PNG и оптимизированном WebP, включая растровую карту «Премиальный атлас».
- `docs/superpowers/specs/2026-08-07-norravia-website-design.md` — утверждённый дизайн.
- `docs/superpowers/specs/2026-08-09-arctic-editorial-redesign-design.md` — утверждённая спецификация редизайна Arctic Editorial.
- `docs/superpowers/plans/2026-08-09-arctic-editorial-redesign.md` — план реализации редизайна.
- `PRODUCT.md` — дизайн-паспорт назначения, аудитории и характера бренда.
- `AGENTS.md` — постоянные правила проекта.
- `README.md` — инструкция по запуску и использованию.

## Установка зависимостей

Зависимости не требуются. Сайт создаётся на чистых HTML, CSS, JavaScript и SVG.

## Запуск

После реализации открыть файл `index.html` в современном браузере.

## Внешние программы и сервисы

Пять изображений были созданы встроенным генератором изображений. Готовый сайт не обращается к генератору или другим внешним сервисам. Публикация будет выполняться через GitHub Pages.

## Важные решения

- Один самостоятельный HTML-файл выбран для простого запуска и передачи.
- Карта будет встроенной SVG-графикой, чтобы не зависеть от внешнего картографического сервиса.
- Формы, email, пароли, регистрация и сбор персональных данных исключены по решению пользователя.
- Мини-самолёт следует за направлением прокрутки сбоку экрана, не привязан к курсору и использует ограниченное безопасное перемещение внутри окна.
- Страница будет полностью статической и пригодной для GitHub Pages.
- Информация о выбранном направлении остаётся внутри раздела карты и не использует фиксированное или липкое позиционирование.
- Выбор направления является осознанным действием: данные обновляются только после нажатия, а не при наведении.
- Главный лайнер и документы первого и последнего экранов являются единым локальным WebP/PNG-изображением, поэтому перспектива, свет и тени совпадают и сайт не зависит от внешнего сервера.
